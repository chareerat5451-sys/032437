# ระบบสอบออนไลน์ แบบทดสอบปลายภาค พล 032437 ทักษะและการสอนกีฬามวยไทย

ใช้ข้อสอบปรนัย 4 ตัวเลือก 60 ข้อ (บทละ 5 ข้อ ครบ 12 บท) เวลา 90 นาที ตรวจคะแนนอัตโนมัติ แล้วแปลงเป็น 30 คะแนน (ข้อละ 0.5 คะแนน) ข้อสอบชุดนี้ตรงกับไฟล์ "ข้อสอบและแบบประเมิน_พล032437_มวยไทย.docx"

## โครงสร้างไฟล์

```
public/index.html                  หน้าสอบของนักศึกษา
public/admin.html                  หน้าผู้ดูแล (ปุ่ม "อาจารย์: ผู้ดูแลการสอบ" บนแถบเมนู หรือ /admin)
netlify/functions/api.mjs          API ฝั่งเซิร์ฟเวอร์ (Netlify Functions)
netlify/functions/lib/core.mjs     ตรรกะการสอบ การตรวจคะแนน และการกันโกง
netlify/functions/lib/questions.mjs คลังข้อสอบและเฉลย (อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น)
netlify.toml                       การตั้งค่า Netlify และ security headers
tests/                             ชุดทดสอบและเซิร์ฟเวอร์ทดสอบในเครื่อง
```

ผลสอบเก็บใน Netlify Blobs (ชื่อ store: `muaythai-final-exam`) ไม่ต้องตั้งฐานข้อมูลเพิ่ม

## ขั้นตอนติดตั้ง

### 1. อัปโหลดขึ้น GitHub
1. เข้า github.com แล้วกด **New repository** ตั้งชื่อ เช่น `muaythai-final-exam` เลือก **Private** แล้วกด Create
2. ในหน้า repo กด **uploading an existing file**
3. แตกไฟล์ zip แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ (public, netlify, tests, netlify.toml, package.json, README.md, .gitignore) ลงไป
4. กด **Commit changes**

### 2. เชื่อม Netlify
1. เข้า app.netlify.com → **Add new site** → **Import an existing project** → เลือก **GitHub** → เลือก repo ที่สร้างไว้
2. หน้า Build settings ปล่อยค่าตามเดิม (ระบบอ่านจาก `netlify.toml`: Publish directory = `public`, Functions directory = `netlify/functions`) Build command เว้นว่าง
3. กด **Deploy**

### 3. รหัสผ่านผู้ดูแล
- รหัสผ่านผู้ดูแลตั้งไว้ในระบบแล้ว ใช้ได้ทันทีหลัง deploy ไม่ต้องตั้งค่าเพิ่มใน Netlify (ในโค้ดเก็บเป็นค่าเข้ารหัส SHA-256 ไม่มีตัวรหัสจริงอยู่ใน GitHub)
- กุญแจเซ็นสิทธิ์ผู้ดูแลระบบสุ่มสร้างเองครั้งแรกและเก็บใน Netlify Blobs
- หากต้องการเปลี่ยนรหัส: Netlify → **Site configuration** → **Environment variables** → เพิ่ม `ADMIN_PASSWORD` = รหัสใหม่ แล้ว **Deploys → Trigger deploy** (ค่าใน Netlify จะใช้แทนรหัสเดิม)
- หากเคยเพิ่ม `ADMIN_PASSWORD` ไว้แล้ว ระบบจะใช้ค่านั้น ไม่ใช่รหัสที่ตั้งในโค้ด

## วันสอบ

### ตั้งวันเวลาเปิด-ปิดสอบ (แนะนำให้ตั้งล่วงหน้า)
1. เปิดเว็บไซต์ กดปุ่ม **อาจารย์: ผู้ดูแลการสอบ** ที่แถบเมนูด้านบน แล้วใส่รหัสผ่าน
2. ในส่วน **ตั้งค่าการสอบ** เลือก **เปิด-ปิดตามวันเวลาที่กำหนด**
3. ใส่ **วันเวลาเปิดสอบ** และ **วันเวลาปิดสอบ** (หรือกดปุ่มตั้งเร็ว "ปิด = เปิด + 90 นาที") ใต้ช่องจะแสดงวันเวลาแบบไทย (พ.ศ.) ให้ตรวจทาน
4. กด **บันทึกการตั้งค่า** แถบสถานะด้านบนจะบอกว่า "รอเปิดสอบ" พร้อมเวลาที่เหลือ
5. ก่อนเวลาเปิด หน้านักศึกษาจะแสดงวันเวลาสอบและนับถอยหลัง ปุ่มเริ่มสอบจะกดได้เองเมื่อถึงเวลา โดยไม่ต้องรีเฟรช
6. เมื่อถึงเวลาปิด ระบบปิดรับและส่งคำตอบของผู้ที่ยังสอบอยู่ให้อัตโนมัติ แม้จะเริ่มสอบช้า (เวลาสอบของแต่ละคน = 90 นาที หรือถึงเวลาปิด แล้วแต่อย่างใดถึงก่อน)

โหมดอื่น
- **เปิดทันที**: เปิดให้เข้าสอบตอนนี้เลย ใส่เวลาปิดได้ถ้าต้องการ
- **ปิดการสอบ**: นักศึกษาเข้าสอบไม่ได้
- เลื่อนเวลาปิดให้เร็วขึ้นระหว่างสอบได้ ระบบจะปรับเวลาของผู้ที่กำลังสอบให้ทันที ส่วนการให้เวลาเพิ่มรายบุคคลใช้ปุ่ม "ต่อเวลา"

### ระหว่างและหลังสอบ
1. ติดตามในตารางผลสอบ (รีเฟรชทุก 15 วินาที): ใครกำลังสอบ เหลือเวลาเท่าไร ทำผิดกี่ครั้ง
2. เมื่อสอบเสร็จ กด **ดาวน์โหลดคะแนน (CSV)** ซึ่งเปิดใน Excel ได้ทันที (ภาษาไทยไม่เพี้ยน) นำคอลัมน์ "คะแนน (30)" ไปกรอกในใบลงคะแนน

### เครื่องมือผู้ดูแล
| ปุ่ม | ใช้เมื่อ |
|---|---|
| ดู | ดูคำตอบรายข้อ (เรียงตามเลขข้อในเฉลย Word) และบันทึกเหตุการณ์ทั้งหมด |
| ปลดล็อกอุปกรณ์ | เครื่องนักศึกษาเสียและต้องย้ายไปสอบเครื่องอื่น (เวลาเดินต่อ คำตอบเดิมยังอยู่) |
| ต่อเวลา | ให้เวลาเพิ่มรายบุคคล เช่น อินเทอร์เน็ตล่ม |
| บังคับส่ง | ปิดการสอบของคนนั้นทันทีและตรวจคะแนน |
| ลบ/ให้สอบใหม่ | ลบข้อมูลทั้งหมดของรหัสนั้น ให้เริ่มใหม่ (คะแนนเดิมหายถาวร) |
| วิเคราะห์ข้อสอบ | ค่าความยาก p, อำนาจจำแนก r (กลุ่มสูง-ต่ำ 27%) และจำนวนผู้เลือกแต่ละตัวเลือก |
| ดาวน์โหลดคำตอบรายข้อ (CSV) | คำตอบ ก/ข/ค/ง ของทุกคนเรียงตามข้อในเฉลย ใช้วิเคราะห์ต่อ |

## ระบบป้องกันการโกง

ฝั่งเซิร์ฟเวอร์ (นักศึกษาแก้ไขไม่ได้)
- เฉลยไม่ถูกส่งไปที่เครื่องนักศึกษาเลย ตรวจคะแนนบนเซิร์ฟเวอร์เท่านั้น
- สุ่มลำดับข้อและลำดับตัวเลือกใหม่ให้แต่ละคน คนข้างกันจะเห็นข้อสอบไม่เหมือนกัน
- จับเวลาบนเซิร์ฟเวอร์ ปรับเวลาในเครื่องเพื่อยืดเวลาไม่ได้ หากปิดเครื่องหนี ระบบจะส่งคำตอบที่บันทึกไว้ให้เองเมื่อหมดเวลา
- 1 รหัสนักศึกษาสอบได้ครั้งเดียว และผูกกับอุปกรณ์ที่เริ่มสอบ หากมีคนพยายามเข้าด้วยรหัสเดียวกันจากเครื่องอื่นหรือใช้ชื่อไม่ตรง ระบบจะปฏิเสธและแจ้งในหน้าผู้ดูแล
- นับจำนวนครั้งที่ทำผิด ครบตามที่กำหนด (ค่าเริ่มต้น 3 ครั้ง) ส่งคำตอบอัตโนมัติ

ฝั่งหน้าสอบ
- บังคับโหมดเต็มจอ ออกจากเต็มจอจะถูกบันทึกและบังข้อสอบจนกว่าจะกลับเข้าเต็มจอ
- สลับแท็บ สลับโปรแกรม หรือย่อหน้าต่าง จะถูกนับเป็นการทำผิด พร้อมแจ้งเตือนจำนวนครั้ง
- ห้ามคัดลอก วาง คลิกขวา ลากเลือกข้อความ สั่งพิมพ์ และปุ่มลัด (Ctrl+C/V/P/S/U, F12, DevTools)
- บันทึกการกด PrintScreen การเปิดหน้าสอบหลายแท็บ และขนาดหน้าต่างที่ผิดปกติ (อาจเปิด DevTools)
- ลายน้ำรหัสและชื่อผู้สอบทั่วหน้าจอ หากมีภาพหน้าจอหลุดออกไปจะรู้ว่ามาจากใคร
- บันทึกคำตอบอัตโนมัติทุกครั้งที่เลือก เน็ตหลุดก็เก็บไว้ในเครื่องก่อน แล้วส่งเมื่อกลับมาออนไลน์

### ข้อจำกัดที่ควรทราบ
- ระบบเว็บไม่สามารถกันการถ่ายรูปหน้าจอด้วยโทรศัพท์ หรือการถามคนข้าง ๆ ได้ ควรมีผู้คุมสอบในห้อง
- การยืนยันตัวตนใช้รหัสนักศึกษาและชื่อ จึงควรเปิดรับเข้าสอบเฉพาะช่วงที่คุมสอบ และตรวจรายชื่อในหน้าผู้ดูแลเทียบกับผู้เข้าห้องสอบ
- iPhone/iPad ไม่รองรับโหมดเต็มจอบนหน้าเว็บ ระบบยังตรวจการสลับแอปได้ แต่ควรให้สอบด้วยคอมพิวเตอร์ (Chrome หรือ Edge) เป็นหลัก
- การโหลดหน้าใหม่ (refresh) ระหว่างสอบอาจถูกบันทึกเป็นการออกนอกหน้าสอบ 1 ครั้ง

## แก้ไขข้อสอบ
แก้ไฟล์ `netlify/functions/lib/questions.mjs` (แต่ละข้อมี `q` คำถาม, `o` ตัวเลือก 4 ตัว, `a` ตำแหน่งคำตอบที่ถูก 0=ก 1=ข 2=ค 3=ง) แล้ว commit ใน GitHub ระบบ Netlify จะ deploy ใหม่ให้อัตโนมัติ **ห้ามแก้ระหว่างที่มีคนกำลังสอบ**

## ทดสอบในเครื่องก่อนใช้จริง (ไม่บังคับ)
ต้องมี Node.js 18 ขึ้นไป
```
npm install
npm test          # ทดสอบตรรกะการสอบทั้งหมด
npm run dev       # เปิด http://localhost:8888 และ /admin (ใช้รหัสผ่านผู้ดูแลเดียวกับระบบจริง)
```
ข้อมูลในโหมดทดสอบเก็บในหน่วยความจำ ปิดโปรแกรมแล้วข้อมูลหาย

แนะนำให้ทดลองสอบจริงบน Netlify 1–2 คนก่อนวันสอบ แล้วกด "ลบ/ให้สอบใหม่" เพื่อล้างข้อมูลทดลอง
